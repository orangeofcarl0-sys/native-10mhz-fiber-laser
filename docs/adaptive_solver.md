# P0 自适应求解与候选搜索

新入口为 `attractor_search.py`，CPU 精度参考实现。旧 `scan.py` / CuPy 批量地图继续保留用于复现历史数据，**不会自动变成新算法结果**。`MAP_GPU` 不控制新求解器。本次改造不改变 EDF/CNT 物理参数或 20.42 m 腔长。

## 1. 真实传播与候选搜索分开

`AdaptiveSolver.step()` 每次只接受一个数值边界通过的真实往返。EDF 仍使用 `n_next=n+(A/B-n)(1-exp(-B*T_R))`，`rates_a/rates_b` 保存全部 EDF 单元的率，而不是只保留平均反转。

搜索先短暂冻结反转观察快场。如果最近8圈复场残差与能量CV均<1%，才允许用平均率做解析慢增益更新。解析步最长1000个名义RT，且每个单元反转改变量限制在0.002以内。冻结阶段能量相邻变化超过20%时立即放弃本块加速；快场未松弛时回到真实动态搜索。

**加速段不是物理时间轨迹。** 它只找候选，不判断Q开关、松弛振荡或稳定性，也没有已验证的普遍加速倍数。搜索预算耗尽后无论是否找到候选，都切回真实动态检查，并重新计算验证年龄。

验证年龄累计 `sum(T_R / max_z(tau_eff))`，其中 `tau_eff=1/B`。至少达到5，才允许标记局部递归验证；更换时间或EDF网格后重新累计。真实RT计数与加速迭代数分别记录。`direct_rounds` 是计算预算，不是充分收敛条件：预算用尽不能自动通过。

## 2. 数值边界：回退后重算

- 时间坐标：每圈尝试整数样本周期平移，把主峰居中；只有边缘占比下降才接受。保留全部卫星脉冲，不裁剪。此处使用精确整数平移，诊断仍支持亚样本对齐。要求窗口外有足够CNT恢复间隔；不追踪绝对到达时间。
- 频谱占比>1e−10：从本圈入口的干净检查点把dt减半，在相同时间窗上带限插值，重算整圈。
- 时间边缘占比>1e−8：从干净检查点两端补零扩窗，重算整圈。
- 同时触发：扩窗与dt减半一起做。每次重网格验证离散能量守恒。
- 检查光纤内部的已接受无源子步、EDF出口、腔内最终场与OC输出，尽早中断超限试算。EDF内部暂不逐子步做频谱哨兵，其出口和粗/细EDF对照参与检查。

被拒绝的一圈不更新接受圈数，也不重复消耗增益。重网格不会修复过去已经混叠的输入；外部检查点必须注明数值可信度。达到最小dt/EDF步长、最大样本数/窗口或重试上限时保存检查点并返回 `numerically_unresolved`，不得归为物理不可行。

## 3. 空间误差控制

无源段保留 Strang SSFM。对每个试探步比较一次h与两次h/2，复场相对误差估计为差值/3；接受两半步结果。每段误差预算按 `z_rtol*h/L` 分配，并限制估计非线性相位。此为局部误差控制，不是整个非线性长期轨迹的严格全局误差界。

EDF独立执行h网格与h/2网格单程对照，检查复场误差及空间反转误差。超限时将EDF网格减半、保守重映射检查点反转，再重算整圈。反转数组保存单元平均值，按新旧单元重叠长度转移，保持平均反转/总反转粒子数。默认初始EDF步长0.05m，下限0.003125m；阈值见 `adaptive_solver.DEFAULTS`。

`validate_edf_mesh.py` 对三个归档输入独立比较0.1/0.05/0.025m，其余时间采样固定。边界快照仅是数值压力输入，不能据此认证物理解。

## 4. 初始化与延续

保留 `legacy` 相同人工初态用于公平拓扑对照；`pump` 先用泵浦独立稳态纵向传输计算反转，再加入0.01pJ高斯种子；`noise` 使用带限、固定随机种子的弱场，**不是ASE模型，也不等价于真实噪声自启动**。泵浦独立稳态代表预充能EDF，不是从未泵浦冷腔开始。

泵浦/GDD上下扫分别独立初始化。相邻点继承腔内场、反转、CNT状态和时间网格；默认遇到未收敛点就停止该方向；仅显式设置 allow_unconverged=True 时允许探索用warm start，并明确标注，不能称为吸引子continuation或据此宣称滞回。数值未解析状态不传递。EDF网格必要时保守重映射。

```python
from attractor_search import run_point, continuation, multi_seed

# 单点：搜索预算和真实RT预算分别设置
result, state, dt = run_point(search_blocks=10, direct_rounds=10000)

# 两拓扑分别调用；非共用最终状态
continuation('OC_CNT', .2, .3, [5, 10, 15, 20], direct_rounds=10000)
continuation('CNT_OC', .2, .3, [.1, .15, .2], axis='gdd', pump_mW=10,
             name='gdd_path', direct_rounds=10000)
multi_seed(pump=.01, direct_rounds=10000)
```

这些是可能耗时较长的研究计算；默认CPU精度路径优先保证可审计性，不承诺比旧GPU代码更快。

## 5. 稳定性分类

保留最近80个真实输出场和完整EDF反转剖面；网格变化后清空此历史。检查周期1–16，每个周期至少有4次重复，并比较：共同时移/全局相位对齐后的复矢量场、总强度、时间分辨Stokes分量、逐周期能量误差、周期平均能量CV、纵向反转相对L2与最大漂移。不会移除真实偏振旋转。

分类为：记录不足、场已衰减、暂定周期递归、经过有效增益年龄检查的局部递归，以及非稳态/未解析。另列周期、窗口内单峰与目标能量是否满足。未收敛不直接称为混沌；周期递归不直接证明扰动吸引稳定。

即使 `local_recurrence_validated`，也只是当前局部窗口的有限记录检查。最终工程稳定单脉冲仍须更严格网格对照、独立扰动、多个初态，以及全腔卫星竞争验证。结果始终保存 `full_cavity_single_pulse_certified=False`。Floquet、跨时间槽共享增益、多脉冲竞争、RK4IP、GPU prefix scan与主动采样尚未实施。

## 6. 逐单元累计增益年龄（2026-09-19更新）

直接物理RT阶段累积 Gamma[j] += B[j,k]/f_rep，然后取 min_j Gamma[j]；不是每圈先取最小B再求和。gain_memory_max=exp(-gain_age_min)只表示沿已实现速率历史的条件线性松弛系数，不能替代耦合系统的扰动或Floquet稳定性检查。冻结搜索和加速反转跳步不计入年龄；切换数值网格时自适应认证路径保守重置，保存逐单元数组。新门槛为7，约对应9.12e-4的条件系数，历史报告仍保留原门槛口径。

新增run_gain_relaxation.py从g08_c53@600的完整状态直接续算，未知的前600圈年龄不补算。初始预算1万真实圈，若年龄仍不足7，则最多2万圈；预算用尽不宣称收敛。检查1–16圈递归和局部网格差异，周期递归只是候选，还需要长期保持、独立扰动与全腔验证。
