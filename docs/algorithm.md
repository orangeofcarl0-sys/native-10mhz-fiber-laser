# 算法与诊断

研究问题：在固定 20.42 m 腔长与相同物理参数下，交换相邻 OC、CNT 的顺序，是否出现稳定的 0.1–0.5 nJ 单脉冲输出？

## 状态、单位与传播顺序

场 `a[case, polarization, time]` 单位 sqrt(W)，强度为两偏振模方之和。时间用 ps，因而 `sum(abs(a)**2)*dt` 的单位是 pJ。反转 `pop[case, EDF cell]` 为无量纲比例，CNT 吸收 `q[case]` 为无量纲损耗。批量轴是互不耦合的独立腔，不混合场。

一圈：0.10 m SMF → 1.50 m EDF → 0.05 m SMF → 0.72 m SMF → PC → OC/CNT → 接续损耗 → 剩余 SMF → NDF → 混合器件损耗/PDL。输出取 OC 当地场，不能拿腔内其他位置的脉宽替代。

EDF 长度固定，NDF 等长替换 SMF：

```
L_NDF = (GDD - 0.0459*1.5 + 0.0217*(20.42-1.5))/0.1217
L_SMF = 20.42 - 1.5 - L_NDF
```

`config()` 检查总长与 Σβ₂L。NDF 的 β₂=+0.10 ps²/m 和 γ=0.004/(W·m) 为模型假设，未对应认证型号。

## 数值操作与物理机制

1. **光纤色散与双折射：** FFT 域线性半步含二阶/三阶色散、双折射、DGD。旋转 Jones 基底后传播，再转回实验室坐标。
2. **Kerr：** 圆偏振基下更新非线性相位，再变回线偏振。无损条件下不改变总能量。
3. **EDF：** 每个空间单元使用当前反转形成 Lorentzian 增益谱。泵浦随吸收沿程衰减。用单元中点泵浦与增益加权平均信号构造跃迁率 A、B，更新 `n_next = n + (A/B-n)*(1-exp(-B*T_R))`。这保留慢增益储能，不强制每圈瞬时平衡。
4. **CNT：** `dq/dt=(q0-q)/tau-q*P/E_sat`。每个采样区间用冻结功率的指数递推，区间中点吸收作用于场；透过率 `1-l_ns-q`。窗口外按恢复时间自由恢复。高 OC 改变 CNT 看到的局部功率，顺序差异通过该项产生。
5. **输出/损耗：** 先施加 OC 额外插损，再按 sqrt(OC) 和 sqrt(1-OC) 分场。PC 为无损 Jones 变换，其他损耗按场幅度换算 dB。

初始化为 10 ps 强度标准差的高斯场，使用近似小信号净增益为零的反转猜测。两拓扑初始场、反转、CNT 状态完全相同。只初始化一次，迭代中无能量归一化。初态不是自启动模型，也不是泵浦稳态解。

## 诊断与筛选

MAT `trace[round,case,metric]` 12 列依次为：输出能量 pJ、峰值 W、主峰 FWHM ps、显著峰数、对齐后强度残差、时间边缘能量占比、频谱边缘占比、CNT 入射能量 pJ、CNT 入射峰值 W、最小 CNT 吸收、最大反转平衡差、平均反转。

时间边缘为 |t|>0.45×窗口宽度；频谱边缘为 |ω|>0.9π/Δt。每 20 圈检查占比 >1e−6 / >1e−8、下溢或非有限能量；触发即停止并标记未解析。停止不是物理不可行证明。

峰数以高度与 prominence 均 ≥峰值的 10% 统计。强度残差通过互相关求平移（抛物线亚采样修正）、FFT 平移后求相对 L2；保留能量变化，不做幅度归一化。

严格初筛要求：完成规定圈数且边界通过；最后 100 圈全部能量在 100–500 pJ，能量 CV<1e−4；最后 64 圈全部单峰且最大强度残差<1e−3。该判据针对逐圈近似重复的脉冲，不代表所有呼吸锁模定义。缩短扫描只适合调试，不能据此认证稳定性。

长程验证从保存的**腔内最终场**继续，不从耦出的场回灌；重采样检查能量守恒，再施加 ±10% 能量扰动。它检验候选状态是否持续存在，而非只观察某一圈的能量命中。
