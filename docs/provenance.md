# 结果来源与发布边界

`results/reference/` 与 `docs/report.html` 保存本次双拓扑地图研究的结果快照。原始粗/细网格共 1280 条轨迹，涵盖 640 个独立物理组合；不是 1280 个不同参数点。原始大型 MAT 在研究工作目录保留，不上传 Git；可使用本仓库重算。

| 网格 | 参数点 | 边界通过 | 短时目标能量单峰 | 严格初筛通过 |
|---|---:|---:|---:|---:|
| 粗 | 640 | 104 | 3 | 0 |
| 细 | 640 | 264 | 8 | 0 |

观察到的 8 个短时状态不是 8 个稳定解。三组接近目标的设置各做三种能量扰动，长程轨迹最终均触发时间或频谱边界，并出现显著能量变化/多峰；尚未认证稳定可行区。谱图是局部窗口输出场包络，不是解析 10 MHz 梳齿的射频谱。

发布整理只改变参数存储、代码排版、输出目录和 GPU 环境加载；传播方程与扫描网格保持原设定。旧 MAT 中未使用/过期的标量配置未带入。验证脚本改用正式扫描的确定性初始化；历史验证 JSON 与新运行记录分开放置。

原研究运行环境：Python 3.11、NumPy 2.4.6、SciPy 1.17.1、Matplotlib 3.11.1。CPU/GPU 的历史一致性和局部网格检查记录位于 reference 目录。发布后的 CPU 自检由 CI 重跑；GPU 须在使用者的 CUDA 环境重新运行 `validate_gpu.py`。

无硬件实验；NDF/CNT/增益参数未对具体器件联合标定。代码与结果不能直接承诺实际器件性能。公开仓库不含泵浦采购文件、个人路径或本机 CUDA 运行库。
